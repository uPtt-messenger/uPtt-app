01 How it works

How uPtt turns PTT mail into a conversation

1995

In a PTT mailbox, every message looks the same

Each one is a single line titled 你收到使用 uPtt 傳送的訊息, “you received a message sent with uPtt”. To read one you open it; to answer you write a whole new letter.

uPtt reads every one for you, in the background

Every 5 seconds it polls the mailbox, recognises uPtt’s format, restores the embedded [uPtt-ts] timestamp, then deletes the delivered message from PTT so the mailbox stays clean.

And they become a real conversation

Grouped by sender, ordered by time, with unread counts by each contact. Regular PTT mail is never deleted; it stays in PTT untouched.

04 Architecture

Two sessions,
never waiting

With one PTT account, uPtt keeps two sessions open: one for sending and receiving, one for presence lookups. However slow a lookup gets, your messages never wait on it.

  • Main session Logs in, polls mail and waterballs every 5 seconds, sends messages.
  • Query session Starts 10 seconds after the main login and takes the user lookups that can block for seconds. It never kicks the main session when it reconnects.
  • Shared reconnect throttle If both drop at once, they reconnect in turn at least 5 seconds apart, avoiding PTT’s “logging in too often”.
05 Security & privacy

Your conversations live only on your computer. No relay server. No sign-up. No tracking.

  • 01

    Local SQLite

    History and settings live in a database on your machine, with accounts fully isolated by account_id.

  • 02

    Two connections, that’s all

    Straight to PTT’s own server, ptt.cc, plus the GitHub API to check for new versions.

  • 03

    Code signing

    Releases are signed by SignPath.io and verified by the SignPath Foundation, so you know the download hasn’t been tampered with.

  • 04

    Leak-proof CI

    TruffleHog secret scanning, Bandit static analysis, pip-audit, and canary tests that catch any password leak.

While using uPtt, don’t delete mailbox contents by hand from another PTT client.

uPtt syncs by mail order, so manual deletions can cause sync errors or the wrong mail being removed. uPtt only ever deletes messages in its own format; if you’re still worried, turn on mailbox backup to external email in PTT’s settings.
